# Java String

String представляет неизменяемую строку; строковые литералы дают экземпляры этого класса. API использует UTF-16: индекс char и Unicode code point могут различаться. Equals сравнивает содержимое, == для ссылок — идентичность. Преобразование строки в байты требует выбранной кодировки.
