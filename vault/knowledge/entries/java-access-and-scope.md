# Java Access Control and Scope

Scope определяет участок программы для обращения по простому имени; accessibility — допустимость обращения к сущности. Public/protected/private/package access работают вместе с границами модулей. Вход — место обращения и объявление; результат — разрешённое связывание имени или ошибка компиляции.
