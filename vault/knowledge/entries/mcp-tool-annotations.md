# MCP Tool Annotations

`annotations` — необязательные метаданные определения MCP-инструмента, характеризующие его поведение. Они помогают клиенту и модели понять заявленные свойства инструмента.

Спецификация предупреждает: аннотации не являются доверенным свидетельством поведения, если пришли с недоверенного сервера. Это свойства **описания** инструмента, а не механизм принудительного применения политики.
