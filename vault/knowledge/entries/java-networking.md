# Java Networking

Java.net задаёт адреса, сокеты, URI/URL и сетевые соединения; java.net.http — HTTP client и WebSocket API. Вход — конечная точка и данные; выход — обмен или ошибка. Протокольное ожидание, таймауты и завершение соединения относятся к контрактам конкретного API.
