# Java Syntax and Semantics

Лексика и грамматика задают допустимый текст, семантика — вычисление выражений и переходы управления. Вход — исходный код; результат анализа — допустимая программа либо диагностика. Нормальное и резкое завершение различаются; definite assignment проверяется до исполнения.
