# Java Primitive Types

Восемь примитивных типов: boolean, byte, short, int, long, char, float, double. Они задают диапазоны и операции; char представляет кодовую единицу UTF-16. Целочисленное переполнение и округление floating-point следуют правилам языка. Примитивное значение отличается от объекта-обёртки.
