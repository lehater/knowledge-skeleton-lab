# Python Special Methods

Специальные методы связывают классы с операциями языка: __len__, __iter__, __getitem__, __add__, __call__ и другие определяют поведение объектов в синтаксических конструкциях. Вход — операция над объектом; выход — результат согласно соответствующему протоколу либо исключение.

Для неявных вызовов специальные методы обычно ищутся на типе, поэтому присваивание метода отдельному экземпляру может не изменить поведение встроенной операции. Метод следует реализовывать с полным контрактом операции, включая допустимые результаты и отказ. Протоколы поддерживают полиморфизм без обязательного общего пользовательского базового класса.
