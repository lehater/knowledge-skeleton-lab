# Java Platform and Standard Library

Java SE задаёт стандартные API для данных, ввода-вывода, сетей и других задач. Это библиотечный слой вокруг языка. Входы и выходы определяются контрактами API; состав Java SE следует отличать от специфических API JDK и сторонних библиотек.
