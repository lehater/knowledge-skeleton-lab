# Java Packages and Modules

Пакеты организуют имена типов, модули задают зависимости и границы доступности пакетов. Import сокращает запись имён; доступ проверяется отдельно. Вход — единицы компиляции и дескрипторы модулей; результат — разрешённые имена и проверенные межмодульные обращения.

Основные понятия: [[knowledge/entries/java-package|Java Package]], [[knowledge/entries/java-import|Java Import Declarations]], [[knowledge/entries/java-module|Java Module]], [[knowledge/entries/java-access-and-scope|Java Access Control and Scope]], [[knowledge/entries/java-services|Java Module Services]].
