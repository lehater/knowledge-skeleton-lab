# Static Typing

Статическая типизация задаёт типы выражений и переменных и проверяет допустимость их использования до исполнения. Вход — программа и типовой контекст; выход — типовые суждения либо диагностика. Типы могут быть указаны явно или восстановлены выводом типов. Статическая проверка охватывает предусмотренный системой класс ошибок и может сочетаться с проверками во время исполнения.

Java использует статические типы языка. В Python статический анализ аннотаций — отдельный инструментальный слой над динамическим исполнением. Наличие аннотаций или runtime-проверок само по себе не определяет весь режим типизации.
