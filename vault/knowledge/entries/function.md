# Function

Функция в программировании задаёт вызываемое вычисление с параметрами и результатом. Вход вызова — аргументы и доступное окружение; выход — результат, эффекты либо предусмотренная языком передача управления. Определение вычисления и его вызов — разные этапы. Наличие функции не требует её чистоты или тотальности.

Статус значения первого класса, возможность возвращать несколько результатов, правила аргументов и представление функции определяет язык. Python создаёт function objects; Java передаёт поведение через методы и объекты функциональных интерфейсов. Функция, лямбда-выражение и замыкание обозначают разные аспекты вычисления.
