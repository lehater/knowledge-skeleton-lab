# Java Development Kit

JDK — комплект разработки с инструментами компиляции, запуска, документирования и диагностики. Javac переводит исходники в исполняемый JVM-выход; API модулей jdk.* специфичны для JDK. Комплект и его дистрибутив следует отличать от языка Java, платформенного контракта Java SE и абстрактной JVM.
