# Java SE Platform

Java SE определяет стандартную платформу и набор API модулей java.*. Вход приложения — платформенные контракты; результат — переносимые обращения в пределах спецификации. JVM и JLS задают связанные, но отдельные нормы. API модулей jdk.* не обязаны присутствовать в каждой реализации Java SE.
