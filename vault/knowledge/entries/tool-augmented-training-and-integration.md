# Tool-Augmented Training and Integration

Обучение использованию инструментов формирует способность модели выбирать API, момент вызова и аргументы и учитывать полученный результат. В Toolformer эта способность обучается на автоматически подготовленных примерах с вызовами API, при небольшом числе исходных демонстраций. Результат обучения — поведение модели, а не развёрнутый исполнитель инструмента.

Интеграция при inference подключает такую способность к работающей системе: приложение объявляет функции, принимает предложенные вызовы, запускает код и возвращает результаты модели. Она может использовать уже обученную модель без изменения весов. В harness нужно согласовать обученный формат вызовов с реальными интерфейсами и обработкой результатов; наличие навыка вызова API не предоставляет модели полномочий и не гарантирует работоспособность внешнего сервиса.
