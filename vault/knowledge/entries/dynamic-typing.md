# Dynamic Typing

Динамическая типизация связывает типовые сведения прежде всего с исполняемыми значениями; допустимость операций определяется при выполнении над фактическими значениями. Вход — операция и её операнды; выход — результат либо предусмотренный языком отказ. Переменная не обязана иметь один заранее установленный статический тип.

R7RS §1.1 явно противопоставляет типы значений и статические типы переменных/выражений. Cardelli использует более узкий термин dynamic checking: терминология источников различается. Python допускает смену типа значения, связанного с именем, и дополнительно поддерживает статические type hints. Динамическая типизация совместима с лексической областью видимости.
