# Java Class

Класс определяет поля, методы, конструкторы и правила создания экземпляров. Статические и экземплярные члены имеют разные области состояния; abstract-класс непосредственно не инстанцируется. Вход — объявление типа, затем аргументы конструктора; результат — тип и допустимые экземпляры.
