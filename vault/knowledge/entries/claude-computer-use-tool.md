# Claude Computer Use Tool

Определённый Anthropic клиентский интерфейс инструментов для снимков экрана, управления мышью и клавиатурой. Модель возвращает запросы инструментов, приложение исполняет их в своей среде и передаёт результаты модели. Ответственность за фактическое выполнение действий и доступную среду лежит на приложении.
