# Stateless Replay

Stateless Replay — способ продолжать агентное исполнение, восстанавливая контекст следующего обращения по записанной истории взаимодействия. В обзоре Harness Engineering (§6.1–6.2) он сопоставляется с хранением операционного состояния вне промпта.
