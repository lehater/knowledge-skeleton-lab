# Java Arbitrary-Precision Numbers

BigInteger и BigDecimal предоставляют неизменяемые значения для целочисленной и десятичной арифметики произвольной точности. Вход — числа и правила округления, выход — новые значения. BigDecimal позволяет управлять точностью и округлением; произвольная точность всё равно ограничена доступными ресурсами.
