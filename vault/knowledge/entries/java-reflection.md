# Java Core Reflection

Reflection получает сведения о загруженных классах, полях, методах и конструкторах и позволяет обращаться к ним в рамках ограничений инкапсуляции. Вход — runtime-тип и запрос; выход — метаданные или вызов. Модель отражает JVM-представление, которое не обязано взаимно однозначно соответствовать исходному тексту.
