# Python Standard Library

Стандартная библиотека — распространяемые с Python модули и пакеты для типовых задач: работы с текстом и числами, файлами, форматами данных, ОС, сетью, конкурентностью и диагностикой. Она включает код Python и встроенные модули, предоставляющие системные возможности.

Входы и выходы определяются API конкретного модуля: потоки преобразуют байты и текст, сериализаторы — объекты и формат передачи, тестовые средства — проверки и результаты. Библиотека использует языковые протоколы, но не тождественна спецификации языка. Доступность отдельных возможностей зависит от платформы и сборки; сторонние пакеты устанавливаются отдельно.
