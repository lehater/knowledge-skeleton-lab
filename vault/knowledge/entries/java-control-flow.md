# Java Control Flow

Блоки объединяют инструкции; if, циклы и switch выбирают дальнейший путь. Return, break, continue, throw и yield задают разные причины резкого завершения. Вход — условия и текущее состояние; выход — следующий участок кода, возврат или передача управления.
