# BrowserGym Action Space

Набор примитивов взаимодействия агента с браузерной средой BrowserGym. Включает действия по идентификатору элемента (`click`, `fill`), по координатам, ввод с клавиатуры, управление вкладками и навигацию. Выбранный интерфейс действий определяет, какие операции агент может выразить на очередном шаге.
