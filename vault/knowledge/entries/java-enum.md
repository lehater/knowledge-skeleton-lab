# Java Enum Class

Enum определяет ограниченный набор именованных экземпляров своего класса. Константы могут иметь собственные тела; класс может содержать поля и методы. Вход — объявление набора; результат — тип с фиксированными именованными значениями для выбора состояний и вариантов.
