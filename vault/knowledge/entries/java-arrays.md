# Java Arrays

Массив — объект с фиксированной после создания длиной и индексируемыми компонентами одного типа. Доступ проверяет границы. Ковариантность массивов ссылочных типов сопровождается runtime-проверкой записи и возможным ArrayStoreException. Многомерность представляется массивами массивов, поэтому строки могут иметь разную длину.
