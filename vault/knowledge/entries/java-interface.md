# Java Interface

Интерфейс задаёт ссылочный тип и общий контракт для классов. Он допускает abstract, default, static и private методы; экземплярных полей нет. Класс может реализовать несколько интерфейсов. Объекты создаются через классы или функциональные выражения, соответствующие интерфейсу.
