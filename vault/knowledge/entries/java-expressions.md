# Java Expressions and Evaluation

Выражение вычисляет значение, обозначает переменную либо не даёт значения. Операнды и аргументы оцениваются в установленном порядке, обычно слева направо; short-circuit операции пропускают ненужные вычисления. Выход — значение/эффект или резкое завершение, влияющее на следующие операции.
