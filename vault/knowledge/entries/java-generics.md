# Java Generics

Обобщения параметризуют классы, интерфейсы и методы типами. Bounds задают доступные операции, wildcards — допустимые неизвестные аргументы, inference восстанавливает типы. Вход — параметризованные объявления и контекст использования; результат — статически проверяемая программа. Стирание ограничивает сведения о параметрах во время исполнения.

Основные понятия: [[knowledge/entries/java-parameterized-types|Java Parameterized Types and Bounds]], [[knowledge/entries/java-wildcards|Java Wildcards and Capture]], [[knowledge/entries/java-type-erasure|Java Type Erasure]], [[knowledge/entries/java-type-inference|Java Type Inference]].
