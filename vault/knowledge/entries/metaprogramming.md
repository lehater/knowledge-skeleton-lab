# Metaprogramming

Метапрограммирование использует программы для анализа, построения или преобразования программных представлений: синтаксиса, определений, типов либо исполняемого кода. Вход — код/метаданные и правила обработки; выход — сведения, новое определение или преобразованная программа. Работа может происходить до исполнения либо во время него.

Макросы Scheme преобразуют синтаксические формы; Python metaclasses участвуют в построении классов, AST допускает анализ и преобразование. Java annotations предоставляют метаданные, а обработку выполняет потребляющий инструмент. Рефлексия — связанная возможность наблюдения/обращения к программе; метапрограммирование не требует исключительно runtime reflection.
