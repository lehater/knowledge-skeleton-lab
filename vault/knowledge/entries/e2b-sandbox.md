# E2B Sandbox

E2B Sandbox — создаваемая по требованию изолированная Linux VM для агента. SDK позволяет создать среду, подключиться к ней, изменить timeout, приостановить, возобновить и уничтожить её. Timeout ограничивает время жизни среды; его изменение отсчитывает новый интервал от момента вызова.
