# Java Methods and Functions

Методы задают вычисление с параметрами и результатом. Лямбды и ссылки на методы позволяют передавать поведение через функциональные интерфейсы. Вход — аргументы и получатель, когда он нужен; выход — значение, эффекты либо исключение. Оценка функционального выражения и вызов его тела — разные действия.
