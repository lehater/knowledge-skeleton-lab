# Nominal Typing

Номинальная типизация учитывает идентичность объявления типа при установлении равенства или совместимости типов. Совпадение набора членов само по себе не делает независимо объявленные типы одинаковыми или связанными подтипированием. Вход — объявления и проверяемое отношение; выход — решение по правилам имён, объявленных связей и параметров.

Номинальность относится к конкретному отношению системы типов: язык может сочетать номинальные определённые типы со структурными интерфейсами, как Go. Java использует объявленные связи классов/интерфейсов; Python также имеет номинальное подтипирование наряду с Protocol. Номинальность и время проверки типов — разные оси.
