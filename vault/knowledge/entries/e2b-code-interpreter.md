# E2B Code Interpreter

E2B Code Interpreter — SDK для исполнения кода в E2B Sandbox, доступный для Python и JavaScript/TypeScript. Методы `run_code`/`runCode` сохраняют переменные между вызовами и возвращают результаты, включая графики; операции shell-команд и файлов остаются доступны.
