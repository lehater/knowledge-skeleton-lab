# Evaluation Reference Solution Validation

Проверка известного рабочего решения подтверждает, что задача разрешима и её graders принимают ожидаемый результат. Если корректное решение не проходит, исследуют постановку и проверку. Это проверка измерительного сценария до выводов о возможностях агента.
