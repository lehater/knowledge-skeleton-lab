# Modal Sandbox Snapshot

Снимок Modal Sandbox сохраняет состояние среды для последующего восстановления. Modal различает снимки файловой системы, каталога и памяти. Они применяются для подготовки окружений, повторения экспериментов из одного начального состояния и независимого ветвления изменений.
