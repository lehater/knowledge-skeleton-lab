# Model Context Protocol (MCP)

MCP — открытый протокол интеграции приложений с языковыми моделями, источниками контекста и инструментами. Он определяет взаимодействие между host, client и server с использованием JSON-RPC 2.0. Возможности сервера включают инструменты (Tools), ресурсы (Resources) и шаблоны запросов (Prompts).

Редакция спецификации: **2026-07-28**.
