# Context Engineering

Context Engineering — практика отбора и поддержания информации, передаваемой языковой модели при каждом обращении. В отличие от работы только над формулировкой инструкций, она охватывает историю сообщений, инструменты, внешние данные и другие элементы контекста.

**Вход:** потенциально полезная информация и ограничения контекстного окна. **Результат:** набор релевантных токенов для текущего шага агента.
