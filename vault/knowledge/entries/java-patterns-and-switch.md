# Java Patterns and Switch

Шаблоны проверяют совместимость значения и извлекают компоненты record; успешное сопоставление может вводить переменные. Switch выбирает ветвь по селектору, выражение switch производит значение. Правила охвата и доминирования проверяют допустимость ветвей; область pattern-переменных зависит от потока управления.
