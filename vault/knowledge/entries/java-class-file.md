# Java Class File

Class file — независимое от аппаратуры и ОС бинарное представление класса или интерфейса. Оно содержит информацию, необходимую для загрузки и исполнения JVM. Формат версионируется; переносимость не означает, что старая JVM обязана принимать бинарный код нового формата.
