# Model Judge Calibration

Калибровка model-based grader сопоставляет его вердикты с экспертными оценками на примерах. Ясные рубрики по отдельным измерениям и возможность вернуть неопределённость помогают выявлять расхождения. Назначение — проверить пригодность измерителя для выбранного критерия, а не принять его оценки за безусловную истину.
