# Java Virtual Machine

JVM — специфицированная абстрактная машина для class-представления и инструкций. Она задаёт runtime data areas, frames и операции исполнения. Вход — бинарное представление и данные; выход — результаты операций или исключения. Размещение объектов, GC-алгоритмы и оптимизации выбирает конкретная реализация.
