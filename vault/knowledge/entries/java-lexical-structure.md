# Java Lexical Structure

Исходный текст Unicode проходит лексические преобразования, включая обработку Unicode escapes, затем разделяется на токены. Идентификаторы, ключевые слова, литералы, разделители и операторы поступают синтаксическому анализу. Комментарии и пробелы отделяют элементы; отступы сами по себе блоков не образуют.
