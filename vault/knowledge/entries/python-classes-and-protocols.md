# Python Classes and Object Protocols

Объектная модель связывает состояние и поведение посредством классов, экземпляров, методов и наследования. Определение класса формирует новый объект типа; вызов класса обычно создаёт и инициализирует экземпляр. Метаклассы настраивают создание классов, дескрипторы — доступ к атрибутам.

Специальные методы подключают пользовательские объекты к синтаксису языка и встроенным операциям; ABC задают абстрактные интерфейсы. Вход — определение класса и обращения к объектам, выход — классы, экземпляры и результаты операций. Наследование, реализация протокола и экземплярность имеют разный смысл.
