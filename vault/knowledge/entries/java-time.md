# Java Date and Time

Java.time разделяет момент Instant, локальные дату/время, часовой пояс, Duration и календарный Period. Вход — временные данные и правила зоны; выход — корректно интерпретированные значения. Основные типы неизменяемы и потокобезопасны; локальная дата-время сама по себе не определяет момент.
