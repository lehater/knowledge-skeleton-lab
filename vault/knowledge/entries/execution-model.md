# Execution Model

Модель исполнения задаёт, как программа и её окружение определяют шаги вычисления, состояние и передачу управления. Вход — программа, данные и начальный контекст; выход — допустимое выполнение, результаты, эффекты или незавершение. Абстрактная машина и правила переходов — способы задать такую модель.

Модель отделяет семантические обязательства от внутренней реализации. Python execution frames и Java загрузка/инициализация/JVM раскрывают разные части исполнения; наличие абстрактной машины не означает обязательного интерпретатора или единого формата байткода.
