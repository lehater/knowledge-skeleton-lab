# Service Monitoring

Мониторинг собирает, обрабатывает, агрегирует и отображает количественные данные работающей системы. White-box использует внутренние показатели и логи, black-box проверяет поведение снаружи, как его видит пользователь. Выход — показатели, панели и сигналы для диагностики и оповещения; для постановки диагноза одного симптома недостаточно.
