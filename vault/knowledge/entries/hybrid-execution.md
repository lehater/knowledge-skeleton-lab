# Hybrid Execution

Hybrid Execution — способ ведения состояния, объединяющий воспроизводимую историю взаимодействия с постоянными артефактами вне промпта, например файлами, репозиториями или состоянием сеанса. Такое сочетание описано в обзоре Harness Engineering (§6.1–6.2).
