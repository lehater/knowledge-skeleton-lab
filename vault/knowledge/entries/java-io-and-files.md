# Java I/O and Files

Java.io предоставляет байтовые/символьные потоки и сериализацию; java.nio.file — пути, файловые операции и атрибуты. Вход — данные/пути, выход — прочитанные данные или изменения файлов. Charset определяет преобразование текста; файловая семантика зависит от провайдера. Ресурсы закрываются по контракту.
