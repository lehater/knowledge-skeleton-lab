# Automatic Memory Management

Автоматическое управление памятью передаёт системе обязанность освобождать память по установленным правилам времени жизни или владения. Вход — выделения памяти и изменения состояния владения/достижимости; выход — сохранение нужных объектов и возможность повторного использования освобождённой памяти. Конкретный подход определяет стоимость и момент освобождения.

Сборка мусора и освобождение по автоматическому времени жизни владельца решают эту задачу разными способами. Java требует автоматического управления heap; Python оставляет стратегию реализации. Автоматизация памяти не заменяет своевременное закрытие внешних ресурсов и не исключает удержание ненужных объектов.
