# Java Classes and Interfaces

Классы описывают состояние и поведение экземпляров; интерфейсы задают общие типовые контракты. Специальные формы — enum и record; вложенность организует объявления. Результат — определённые типы и правила создания объектов. Наследование и выбор методов раскрываются отдельно.

Основные понятия: [[knowledge/entries/java-class|Java Class]], [[knowledge/entries/java-interface|Java Interface]], [[knowledge/entries/java-record|Java Record Class]], [[knowledge/entries/java-enum|Java Enum Class]], [[knowledge/entries/java-nested-classes|Java Nested and Anonymous Classes]].
