# Java Package

Пакет задаёт пространство имён для классов и интерфейсов и участвует в package access. Иерархия имён пакетов не предоставляет вложенным пакетам привилегий доступа. Вход — package declaration и единицы компиляции; результат — принадлежность типов именованной области.
