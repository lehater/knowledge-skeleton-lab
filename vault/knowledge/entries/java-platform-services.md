# Java Platform Services

Платформа включает JDBC, XML, logging, management, desktop и security API, помимо базовых контейнеров и I/O. JDBC связывает табличные данные с драйвером: вход — соединение/SQL, выход — результаты или ошибки. Наличие интерфейса платформы не включает сторонний драйвер конкретной СУБД.
