# Java Variables and Final

Переменная имеет статический тип и хранит значение. Final ограничивает повторное присваивание, сохраняя возможность изменения объекта по ссылке. Поля и элементы массивов имеют начальные default-значения; локальные переменные проверяются definite assignment. Неизменность ссылки и неизменность объекта — разные свойства.
