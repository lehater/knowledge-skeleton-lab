# Object

Объект — представленная в программе сущность, с которой связаны данные и допустимые операции. В объектной модели различают идентичность объекта, его состояние и поведение; равенство значений не обязано совпадать с идентичностью. Вход — создание или операция; выход — объект, результат обращения либо изменение состояния.

Объём термина задаёт язык: Python представляет объектами также числа, функции и классы; Java отличает объекты от примитивных значений. Объект не обязан быть изменяемым, а класс — не единственный возможный способ организации объектной модели. Физический адрес памяти не является универсальным определением идентичности.
