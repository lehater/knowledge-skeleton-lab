# Code-Specialized Sandboxes

Песочницы для исполнения кода агента предоставляют интерфейс запуска программы и получения результатов в изолированной среде. Пример специализации — E2B Code Interpreter: он добавляет к операциям команд и файлов исполнение кода с сохранением переменных между вызовами и возвратом результатов, включая графики.
