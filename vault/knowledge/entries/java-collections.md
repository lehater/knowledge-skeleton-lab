# Java Collections Framework

Collections Framework предоставляет общие интерфейсы и реализации контейнеров: List, Set, Queue, Deque и Map. Map хранит соответствия ключей значениям и не расширяет Collection. Порядок, допустимость null, изменяемость и потокобезопасность зависят от конкретного контракта.
