# Нормативная модель v1 — единый Knowledge Graph

**Экспериментальный контракт.** Все узлы Vault — Knowledge; роли «тема», «концепция», «технология» возникают из смысла и отношений, а не из разных типов карточек.

1. [schema.md](schema.md) — формат одного узла.
2. [knowledge.md](knowledge.md) — идентичность и evidence.
3. [relations.md](relations.md) — разрешённые типизированные связи.
4. [taxonomy.md](taxonomy.md) — точная тематическая семантика `broader` / `in_topic`.
5. [discovery.md](discovery.md) — evidence-first создание/пересмотр.
6. [validation.md](validation.md) — статическая и семантическая проверки.

Правила вне `vault/`; история предыдущего контракта v0 доступна в Git. Ни один статус проверки не означает доказанную полноту предметной области.
