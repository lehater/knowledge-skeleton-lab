# Нормативный индекс — экспериментальная модель v0

Модель **кандидатная**; допускаются локальные изменения через явное решение владельца и отдельный коммит с проверкой миграции.

1. [schema.md](schema.md) — узлы, поля, стадии.
2. [taxonomy.md](taxonomy.md) — категории и их многородительская иерархия.
3. [relations.md](relations.md) — направленные типизированные отношения.
4. [discovery.md](discovery.md) — генерация и независимое ревью.
5. [validation.md](validation.md) — требования к целостности и метрики.

Правила размещены отдельно от `AGENTS.md`, чтобы инструкции агента оставались небольшими. Обновлять реальную онтологию по одному примеру или только по желанию модели запрещено.
