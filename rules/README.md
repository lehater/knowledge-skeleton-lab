# Нормативный индекс — экспериментальная модель v0

Модель **кандидатная**; локальные изменения — только через явное решение владельца и отдельный коммит с проверкой миграции.

1. [knowledge.md](knowledge.md) — расположение и ограничения Knowledge.
2. [schema.md](schema.md) — узлы, поля и стадии.
3. [taxonomy.md](taxonomy.md) — граф категорий.
4. [relations.md](relations.md) — направленные типизированные отношения.
5. [discovery.md](discovery.md) — генерация и независимое ревью.
6. [validation.md](validation.md) — требования к целостности и метрики.

Правила находятся вне `vault/`, чтобы Obsidian содержал только графовые данные, шаблоны и представления. `AGENTS.md` остаётся небольшим индексом, а не дублирует нормативную модель. Обновлять онтологию по одному примеру или по желанию модели запрещено.
