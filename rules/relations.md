# Направленные предметные отношения v0

| Поле в source | Цель | Утверждение |
| --- | --- | --- |
| `broader` | category | категория source уже, чем категория target |
| `categories` | category | предмет Knowledge непосредственно отнесён к категории target |
| `specializes` | knowledge | предмет source — более частный **вид** предмета target |
| `part_of` | knowledge | предмет source — составная **часть** целого target |
| `realizes` | knowledge | source является конкретной реализацией абстракции/принципа target |
| `schedules` | knowledge | source планирует исполнение target (на конкретном уровне реализации) |
| `executes` | knowledge | source непосредственно обеспечивает выполнение вычисления target |
| `manages` | knowledge | source управляет жизненным циклом/завершением target |

`specializes` не заменяет `part_of`. `realizes` не означает просто «использует». Категория не является видом предметного Knowledge.

Правила:
1. Одна пара `source + predicate + target` хранится один раз только в исходном узле.
2. Никаких автоматически сохранённых инверсий, транзитивности, симметрии или причинных заключений.
3. Для каждой смысловой связи нужна проверяемая аргументация и при возможности источник в `reports/`; статическая валидность ссылки этого не доказывает.
4. Неуверенные связи оставлять кандидатами **в отчёте**, не добавлять в YAML.
5. `broader`, `specializes` и `part_of` не должны создавать циклы в соответствующих отношениях.
6. `uses`, `depends_on`, `prerequisite`, `related_to` и другие предикаты пока не разрешены. Предлагать их отдельно с вопросом выборки и контрпримерами.

Обратную навигацию обеспечивает поиск входящих рёбер/Backlinks/Typed Graph. Линии в Obsidian Canvas не изменяют семантические утверждения.


## Семейства отношений (не отдельные рёбра)

- **Классификационные:** `specializes`.
- **Структурные:** `part_of`.
- **Реализационные:** `realizes`.
- **Функциональные:** `schedules`, `executes`, `manages`.

Семейства нужны для группировки и визуализации. Конкретные предикаты задают точный смысл связи; два предиката не объединяются лишь из-за сходства названий. Факт про Python `asyncio` формулируется между конкретными Python Knowledge; он не переносится автоматически на общий концепт.
