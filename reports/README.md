# Отчёты экспериментов

Здесь хранятся результаты Discovery и независимого ревью, а **не** скрытые дополнительные узлы графа.

Для каждого запуска создавай отдельный Markdown-файл, например `pilot-001-discovery.md`, со следующими разделами:
- входной scope и версии/URL источников;
- baseline тем и способ его получения;
- список узлов и категорий с обоснованием границ;
- утверждённые в YAML отношения и основания, отдельно спорные кандидаты;
- статическая проверка (команда и вывод);
- независимое семантическое ревью (PASS/FAIL/NOT_RUN, выборка);
- покрытие только относительно baseline, примеры пропусков/дублей, открытые вопросы;
- SHA коммита и сведения о GUI-проверке.

Не редактировать отчёт задним числом так, чтобы исчезли ошибки: новая проверка — новая запись/ревизия.
