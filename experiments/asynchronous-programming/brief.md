# Pilot 001 — Asynchronous Programming

**Статус:** подготовлен, Discovery не выполнялся.

## Цель

Проверить, способен ли агент по ограниченному набору внешних источников создать **семантически осмысленный граф категорий и пустых Knowledge** без содержательных заметок и без опоры на предыдущий чат.

## Scope

Включить языконезависимые понятия асинхронного исполнения: приостановка/возобновление, async/await, coroutine, task/future, event loop, runtime/scheduling, lifecycle/cancellation, structured concurrency, I/O-bound work, backpressure; соседство с concurrency и parallelism описывать аккуратно. Конкретные runtime, API и библиотеки включать **только если они помогают различить смысл**, а не ради количества.

Не включать: обучающие инструкции, подробный API конкретного языка, код, GUI, всю архитектуру распределённых систем и исчерпывающую таксономию программной инженерии.

Опорные источники для старта:
- https://docs.python.org/3/library/asyncio.html
- https://doc.rust-lang.org/book/ch17-00-async-await.html
- https://kotlinlang.org/docs/coroutines-basics.html
- https://learn.microsoft.com/en-us/dotnet/csharp/asynchronous-programming/

Это ориентиры, не готовая исчерпывающая онтология. Перед использованием проверить актуальность и применимость.

## Квота

Максимум **30 Knowledge**. Категорий — только столько, сколько действительно нужно для навигации. Все заметки в состоянии `skeleton / proposed`. Не заполнять тела заметок.

## Приёмка

- Статический валидатор и его тесты PASS.
- Независимое ревью показывает обоснованную границу каждого Knowledge и смысл каждого отношения.
- Нет явно дублирующих понятий.
- Категории можно просмотреть в графе с несколькими родителями.
- Отчёт содержит список покрытых и непокрытых опорных тем, без заявления об абсолютной полноте.
- Запуск Obsidian GUI отделён от статической проверки.
